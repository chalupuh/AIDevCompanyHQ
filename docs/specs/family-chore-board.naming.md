# Naming check: "HiveBoard" and alternatives

Date: 2026-11-07. Method: web searches only (USPTO-record mirrors, App Store and Google Play listings). USPTO TESS was retired and replaced by the Trademark Search system (tmsearch.uspto.gov), which this tool cannot query directly. **This is a screening, not legal clearance.** Before launch the owner should run the exact-term and phonetic search on tmsearch.uspto.gov (classes 9, 41, 42) and ideally ask a trademark attorney.

## Result for "HiveBoard"

- USPTO mirrors (Justia, trademarkdir, markinton): no record found for HIVEBOARD. Nearby marks exist: HIVEIO (registered, enterprise software, Class 9), HIVEFLOW (pending), HIVELABS (Class 35), HIVE (pending application), HIVE LIVE (Class 41). "HIVE" is a crowded prefix in software, so a likelihood-of-confusion objection is possible but not evident for a kids' chore app.
- App Store / Google Play: no app named HiveBoard found. Similar names in beekeeping: HiveFlow, HiveBook, HiveBloom, HiveTracks. These are a different category (beekeeping), but search results for "Hive*" will be noisy.
- General web: no company or product called HiveBoard surfaced.

**Verdict: usable as the working name. Not clearly taken.** Risk is low-to-medium due to the crowded "Hive" prefix. Also check domain and social handles (not done here).

## Alternatives (quick conflict check each)

The kids' chore-app namespace is crowded: Chorely, Choreful, ChoreQuest (several), ChoreStar, ChoreLoop, ChoreHero, Chore Champ, Choreo, Chorly, TidyChore, SmartChores, OwlNest, Chore Pad all exist. Avoid names that are "Chore + word".

| # | Name | Findings | Risk |
|---|------|----------|------|
| 1 | **TidyHive** | USPTO TIDYHIVE (serial 98558031, Class 20 furniture) is marked dead. No app listing found. Keeps the hive theme. | Low (best alternative) |
| 2 | **ChoreHive** | No trademark or app listing found. Falls into the crowded "Chore+" pattern and sits near ChoreHero and ChoreNest. | Low-medium |
| 3 | **BeeDone** | No trademark or app listing surfaced in the search (not exhaustive; short common-word pun, likely used elsewhere). | Medium, unverified |
| 4 | **HoneyDo Kids** | No hits found. "Honey-do list" is a common phrase, so it is hard to protect, and the "Kids" suffix is descriptive. | Medium, unverified |
| 5 | **Chorely** | Already exists as a free family chore app on the App Store (iPad, points and rewards). | High: taken, do not use |

Recommendation: keep **HiveBoard**. If the owner wants a lower-risk hive-themed fallback, **TidyHive**.
